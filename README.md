# MiniMuhsins app stories

The story list for the MiniMuhsins app, published at
**https://minimuhsins.github.io/stories/stories.json**.

- To add or change stories, open this folder in Claude Code and ask, for example:
  *"Add the new Zaynab episode https://youtu.be/XXXXXXXXXXX, values patience and kindness, premiering 1 December 5pm, and make it the first hero card."*
- Every change is checked automatically (`node scripts/validate.mjs`). If the check fails, nothing is published.
- The app keeps its built-in list and the last good download, so a problem here never leaves children with an empty app.

See `CLAUDE.md` for the full format and house style.
